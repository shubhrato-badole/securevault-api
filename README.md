# 🔐 SecureVault API

A secure full-stack notes and task management application with JWT authentication and encrypted storage.

---

## 🚀 Features
- User Authentication (JWT)
- Password hashing using bcrypt
- Notes CRUD operations
- To-Do management
- Protected routes using middleware
- RESTful API

---

## 🛠 Tech Stack
- Backend: Node.js, Express
- Frontend: React
- Database: PostgreSQL

---

## 📂 Project Structure
backend/ → API logic  
frontend/ → UI
